# meinong's tabletop

A realtime multiplayer tabletop to play and prototype games with friends.

## What it does

- Generate unique, sharable `table` urls with persistance
- Each table is a unique playspace where you can place game assets and see/interact with other players
- Games supported include Super Metal Mons, cool jpegs (a Solana art bootleg of Reiner Knizia's Modern Art), Hnefatafl, Go, and Snake; with many more to come
- Generic components such as dice, coins, cards, labels, stickers and much more can be added to supplement the play experience + enable custom game crafting
- Social features such as drawing mode, youtube/soundcloud media embeds and more

created by @urmeinong + GPT 5.3 Codex
